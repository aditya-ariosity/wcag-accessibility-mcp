# Accessibility instruction for Codex

Whenever UI code changes, use the connected a11y-feedback MCP server before declaring the work complete. Audit the affected route at the project's desktop and mobile breakpoints. Fix critical and serious findings, prefer shared component or token fixes for repeated failures, rerun the exact audits, and run existing tests. Report incomplete rules as manual keyboard, focus, screen-reader, zoom/reflow, motion, and content checks. Never claim WCAG conformance from automated results alone.
